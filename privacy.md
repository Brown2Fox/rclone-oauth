# Privacy Policy

**Last updated:** October 14, 2026

## Overview

This application is a personal Google Drive integration using rclone. It is intended solely for accessing and synchronizing files belonging to the application owner.

## Data Access

The application requests permission to access Google Drive files to perform file operations such as listing, downloading, uploading, and synchronizing files.

## Data Storage

Google OAuth credentials are stored locally in the rclone configuration file.

Files may be temporarily cached on the user's device during synchronization.

The application does not operate an independent server or maintain a separate database of Google user data.

## Data Sharing

The application does not sell or share Google user data with advertisers or other third parties. Data is transferred between the user's device and Google Drive as necessary to perform requested operations.

## Data Retention and Deletion

Locally stored OAuth credentials can be removed by deleting the associated rclone configuration or disconnecting the account.

Access can also be revoked through Google Account security settings.

## Security

The application relies on Google's OAuth 2.0 authorization process and rclone for communication with Google Drive.

## Contact

For privacy-related questions, contact the project owner through the GitHub repository.
