# Personal Google Drive Integration

This project is a personal integration for accessing Google Drive using [rclone](https://rclone.org/).

It is used to synchronize personal files, including an encrypted KeePassXC password database, across my own devices.

The integration is intended for personal use only and is not offered as a public service.

## How It Works

The application uses Google OAuth 2.0 to authorize access to my Google Drive account. File operations are performed locally using rclone.
